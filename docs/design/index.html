Design

Round three. The layout is settled — keep it. What restarts is the design language laid over it.

SETTLED IN ROUND TWO

The layout stays. The 4×4 grid of live conversations, the dock, the floating sidebar, the pane header, the composer and the status line are right. Four attempts to improve on them each cost more than they returned, and the control — which changed no layout at all — won.

Round one's mistake is worth keeping in view: it rendered a simpler application than the one that exists, deleting the grid, the dock, the sidebar and the ability to see run state. A design that removes an affordance is not bolder, it is smaller.

What has never been chosen from scratch is the visual system. It grew one decision at a time, each defensible on its own, and the result reads like a stock dark developer app because most of those decisions are the stock answer. Everything below is real, in index.css, and well argued there — which is the point. They are good answers to questions nobody re-asked.

Violet accent (hue 287)The default accent of this generation of AI tools — the least ownable hue currently available.
Greys pulled into the accent's hueSound rule, but it means the accent choice silently determines the entire substrate.
Colour is semantic, never decorativeGenuinely good discipline — but it is a choice, and it means the transcript can say how badly something went, never who did it.

All four are generated from one shared layout by _build.py — same markup, same structural CSS, byte-identical. Only the language block differs: tokens, type, surface model, radius, and the transcript grammar drawn on top. Round two varied palette and layout together and nothing could be compared; here the layout is identical by construction, so anything you see differing is the language and nothing else. Each renders the same session and ends with what it costs. See _language.md.

ROUND FOUR · THE LIVE ONE

app.html — the layout refreshed intentionally rather than additively, with Sheet and Signal swappable live. Six screens: the session grid, a full 2×2, the dock's tasks and terminal, the command palette, the profiles screen and first run. Every state is linkable: app.html#signal/quad. Press L to swap language, 1–6 for screens.

The refresh fixes what was accretion: a navigator rail that never disappears — which removes the reason the window header existed, since the sidebar could not reopen itself — one update surface instead of a card and a banner, a status line that elides to the two facts that change behaviour, and a dock with a vertical tab rail and a this-pane/all scope. See _layout.md.

ROUND THREE · FOUR LANGUAGES, ONE LAYOUT
1

Sheet

DEPTH: NONE

Elevation is deleted — not reduced, removed. One ground, one well for machine text, and every boundary is a hairline. Type and space carry all hierarchy; radius is zero on anything the machine produced and soft on anything human. Colour appears about eight times on the whole screen. Archivo + JetBrains Mono, near-neutral grey, teal-cyan accent.

BUYSTwo surface decisions instead of six. Structurally cannot look like a shadcn app. Colour recovers its force. Radius finally means something.
COSTSHairlines vanish on a bad panel with no fill to fall back on. Popovers must break the rule to float. Coldest of the four.
2

Slab

DEPTH: WEIGHT

Depth as weight rather than lightness. A hard 2px edge means "this is an object", 1px means "this is a division inside one". The loudest type ramp of the four — 700 for structure, uppercase mono for every label — on graphite, with hi-vis yellow-green: a machine-shop palette, not a software one. Instrument Sans + IBM Plex Mono.

BUYSScales best to a full grid — pane boundaries are unmistakable, and focus is an accent edge rather than a 10% lighter border. Nobody else's palette.
COSTS2px edges eat real estate across a 4×4. It is loud. The accent sits only 18° from the success green.
3

Ink

HIERARCHY: TYPE

The one thing the agent produces that is genuinely prose gets set as prose: Newsreader at 14.5px with real leading, in a 62-character column. Everything mechanical stays small and mechanical, so size alone tells you what kind of text you are looking at. Surfaces recede almost to nothing. The calmest of the four.

BUYSThe agent's explanation stops being chrome. Kind-of-text is legible before you read a word, with no colour spent on it. A thing you can sit in all day.
COSTSA serif in a developer tool is a real risk and the likeliest of the four to be wrong. Three faces. Mixed baselines. Big prose costs vertical space.
4

Signal

COLOUR: ACTOR

Overturns the rule that colour is semantic only. Here colour says who: you are blue, the agent is plain ink, the machine is green, a delegated agent is violet — and severity rides on top as amber and rose, the only thing allowed to fill a surface. The claim: in a transcript the first question is not how bad this is, it is who did it. Space Grotesk + JetBrains Mono.

BUYSWho did what is answerable without reading. Delegated agents finally have an identity. Severity keeps its force by being the only filler.
COSTSSpends the best rule the current system has. Seven meanings in colour — and green/rose is exactly the pair that collapses for red-green deficiency. Busiest of the four.

What to look for

  • The layout is identical in all four. If one feels clearer, that is the language doing it — there is no layout variable left to confound it.
  • They are separable. Sheet's surface model works under Signal's colour rule; Ink's prose treatment drops into any of the other three. The four axes — depth, colour meaning, hierarchy, type — can be mixed, and probably should be.
  • Every one drops Geist and violet, because those are the two choices most responsible for the clone problem.

If you want one answer

Sheet's surface model, Ink's treatment of prose, Slab's focus edge. Sheet is the strongest single answer — deleting elevation removes the exact thing that makes dark developer apps interchangeable, and it costs the least. Ink's prose column is the best individual idea here and does not need Ink's serif to work. Signal is the most interesting and the most dangerous: worth trying the actor rule on delegated agents only, where the need is real, before spending it on everything.

Not decided here

Light mode, which for Signal is not an inversion and needs its own tint scale. Motion and streaming. Focus rings. Empty and first-run states. And the token layer itself — whichever wins needs writing properly before any component is converted, which is where this stops being mockups and starts being work.
