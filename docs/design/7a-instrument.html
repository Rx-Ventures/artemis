7A · CONTROL — THE TREATMENT TODAY

Instrument

The treatment that ships today, applied to this round's arrangement so the variable really is the treatment. 3px radii, a solid hairline around every region, 11px uppercase mono for anything that is not prose, 22px controls, and depth deliberately deleted.

It is an instrument panel, and it is a coherent one — round three chose it on purpose. The question this round asks is whether it is what Artemis should look like now.

What this treatment buys

  • Density. Nothing on screen is bigger than it needs to be, which is why four panes fit without apology.
  • The hairline grid is honest. Every region has a visible edge; nothing is ambiguous about where a surface starts.
  • It ships. Zero conversion.

What it costs

  • It reads as a tool from 2015. The 3px radius plus solid hairlines plus uppercase mono chrome is the terminal-emulator idiom; against T3 Code, Codex or Claude Code it looks like a different generation of software.
  • The mono chrome shouts. Uppercase 11px monospace at 0.14em is a strong voice used for ordinary labels — a lot of visual weight spent on words nobody reads twice.
  • No breathing room in the transcript. 9px between messages and a full-width column means prose runs to whatever width the pane happens to be.
